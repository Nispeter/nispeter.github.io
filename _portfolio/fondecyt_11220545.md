## Overview

**Power Tester**, the platform for **FONDECYT project #11220545**. You submit a C++ snippet
through the web app and a pool of machines called *measurers* runs it and reports energy and
performance statistics. Measuring on a dedicated pool is the point: it standardizes results
and removes the bias of whichever machine happens to run the code.

The measurers read **Intel RAPL** counters through `perf`, so the numbers are real hardware
readings — core, package and RAM energy — not estimates.

## Contributions

- **Request handler** — queueing and dispatch of submissions across the measurer pool.
- **Energy-consumption graphs** — per-iteration plots for energy, power, cache and branches, with averages overlaid.
- **Refactoring** of the existing codebase and assorted quality-of-life improvements.

## Tech Stack

- **Front-end:** React
- **Back-end:** Python, Flask, Gunicorn, sockets to the measurer nodes
- **Analysis:** NumPy, pandas, Matplotlib, CSV export
- **Measurement:** `perf` over Intel RAPL, on Linux
