## Overview

**Arcane Dice Roller** is a browser-based **tabletop-RPG companion tool** with a
dark-fantasy theme, bundling everything a game master or player needs at the table into a
single web app.

## Features
- **Dice roller** — d4, d6, d8, d10, d12, d20, d100 and a coin, with **advantage /
  disadvantage** mechanics.
- **Combat initiative tracker** with turn management.
- **Party tracker** — health / status with long-rest support.
- **Oracle deck** — a 22-card "Deck of Many Things"–style tarot draw.
- **Probability tools** — a calculator and a spinning, weight-customizable wheel.
- **Utilities** — timer / countdown and a note-taking system with save / export.
- **Terminal-style command interface** for power users.

## Tech Stack
- **Type:** Client-side web app (JavaScript)
- **Hosting:** GitHub Pages
